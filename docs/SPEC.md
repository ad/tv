# TV Home — спецификация v1

Зафиксировано по итогам обсуждения 2026-10-22. Ориентир для сравнения — [ad/free-my-tv](https://github.com/ad/free-my-tv). Эта версия проще: одно устройство, обычные Views, без вендорских веток.

## Платформа
- Google TV Streamer 4K (Android 14). minSdk 31, targetSdk 36.
- Kotlin, обычные Views, Media3 для видео, без Compose и Leanback: быстрый холодный старт и предсказуемый фокус пульта.
- `applicationId` `dev.ad.tv`, название «TV Home», языки RU/EN по системе.
- Один процесс. Отдельный процесс `:home`, как в free-my-tv, сломал бы общие SharedPreferences между настройками и главным экраном.
- Crash watchdog: 3 падения за 5 минут → `RescueActivity`.

## Главный экран
- Справа сверху кнопки (иконки, подпись при фокусе): видеовходы, все приложения, настройки лаунчера, настройки ТВ. Кнопка входов скрыта, если HDMI-входов нет.
- Лента выключена: крупные часы и дата слева, погода справа.
- Лента включена: часы и погода компактной полосой сверху, лента в середине.
- Погода — MET Norway, с User-Agent:
  - сейчас: температура, «ощущается» (apparent temperature по формуле BoM), ветер;
  - сегодня: мин/макс и осадки в мм;
  - три карточки на следующие дни;
  - обновление раз в 30 минут, кэш на диске.
- Город ищется через Nominatim (OSM). Open-Meteo не используется: из сети пользователя он недоступен.
- Панель избранного: «стекло» без настоящего блюра, баннеры 16:9.
- Фокус при возврате: на плитке последнего приложения. Источник — последний запуск из лаунчера или UsageStats, если выдан доступ; если приложения нет в избранном, на первой плитке.
- Видеовходы: `TvInputManager`, только подключённые HDMI, имена CEC-устройств.

## Фон
- 10 пресетов: однотонные цвета и градиенты.
- Видео: без звука, по кругу, cover-масштабирование, плеер освобождается в `onStop`. Источники:
  - встроенное (flavor `video` берёт папку `video/` как assets);
  - файл из MediaStore (`READ_MEDIA_VIDEO`, файлы кладутся через `adb push`);
  - ссылка http/HLS.

## Лента
- Источники:
  - **CUB (Lampa)** — по умолчанию, без ключа. Режимы: «Сейчас смотрят» `?sort=now_playing`, «Новинки» `?sort=latest`, «Новинки 4K» `&uhd=true`, «Горячее» `top/fire`, «Топ‑100» `top/hundred`;
  - **TMDB** через прокси Lampa (`apitmdb.cub.black` → `cub.best` → `lampa.byskaz.ru`, плюс свой хост) — «В тренде» / «Новинки»;
  - **Кинопоиск** (`api.poiskkino.dev/v1.5`) — «Популярное» за последние 2 года / «Новинки» по цифровой премьере за 90 дней.
- Тип: фильмы, сериалы или оба (вперемешку).
- Картинки с `imagetmdb.com`: w780 для фона, w342 для постеров. Дисковый кэш до 50 МБ, лента обновляется раз в 6 часов.
- Выбранная карточка широкая (фон), остальные — узкие постеры. Подпись под лентой: название · год · тип.
- Карточка «Ещё» в конце ленты, только для CUB при открытии в Lampa: открывает тот же список в Lampa (`lampaActivity`).
- Клик открывает карточку в приложении из настройки «Открывать в»:
  - Lampa: `https://www.themoviedb.org/{movie|tv}/{id}`, без TMDB id — поиск по названию;
  - Кинопоиск: `kpatv://film/<kpHD>`, затем `https://hd.kinopoisk.ru/film/<kpHD>`, иначе просто запуск приложения;
  - NUM: просто запуск приложения.
- Долгое нажатие: «Открыть в…» / «Скрыть». Скрытые хранятся как `key\ttitle`, вернуть их можно в настройках.
- Ключи TMDB и Кинопоиска вводятся в полях настроек (удобно через `adb shell input text`).

## Домашний экран
- ADB изнутри приложения через libadb-android (Wireless debugging, TLS + SPAKE2):
  - первый раз — сопряжение по коду;
  - затем `pm grant WRITE_SECURE_SETTINGS` и `appops GET_USAGE_STATS`;
  - проверка владельцев Wi‑Fi сетей;
  - `set-home-activity`, затем `pm disable-user` для `setupwraith` и `launcherx`.
- Обратно: `pm enable` для обоих пакетов.
- Если выдан `WRITE_SECURE_SETTINGS`, лаунчер сам включает `adb_wifi_enabled` на время команды. Работает только в доверенной Wi‑Fi сети.
- `scripts/setup.sh` — запасной путь с компьютера.

## CI
- Pull request: debug-APK обоих вариантов в artifacts.
- Push в `main`: подписанные release-APK `lite` и `video` плюс `setup.sh` публикуются в GitHub Release `v1.0.<run_number>`. Без секретов с ключом сборка падает.
