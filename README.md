# TV Home

Простой и быстрый лаунчер для Google TV и Android TV 12+. Чистая Java без Gradle и сторонних библиотек.

<img width="1920" height="1080" alt="tv-screenshot" src="https://github.com/user-attachments/assets/82735589-3d9d-45d1-a334-5eb108fd04e5" />

- Большие часы и погода: сейчас, сегодня и три следующих дня (MET Norway). Город выбирается в настройках, поиск через OpenStreetMap.
- Фон: 10 цветовых пресетов или видео без звука по кругу. Видео можно взять файлом с устройства, по ссылке (http/HLS) или встроенное 1080p.
- Справа сверху кнопки: видеовходы (HDMI с CEC-именами), все приложения, настройки лаунчера, настройки ТВ.
- Внизу «стеклянная» панель избранного. При возврате на домашний экран фокус стоит на приложении, из которого вы вернулись. Размер плиток: компактные, средние или крупные.
- IP-камеры в избранном: Настройки → Избранное → «Добавить камеру», адрес `rtsp://…` (H.264 или H.265). Плитка показывает кадр с камеры, нажатие открывает поток, стрелки влево-вправо листают камеры.
- Мышь:
  - обычная USB/Bluetooth-мышь работает сразу: наведение, клик, правый клик — меню, колесо прокручивает;
  - курсор с пульта: кнопка курсора (по умолчанию `BOOKMARK`, переназначается в настройках) показывает указатель, стрелки двигают, OK кликает, удержание OK — долгое нажатие;
  - курсор работает либо только в лаунчере, либо во всех приложениях через службу специальных возможностей.
- Лента новинок: CUB (Lampa, без ключа), TMDB через прокси Lampa или Кинопоиск (poiskkino.dev). Карточки открываются в Lampa, Кинопоиске, NUM или [Soap TV](https://github.com/ad/soap4ad). Лишнее можно скрыть долгим нажатием, нужное — добавить в избранное (см. «Избранное кино»).
- Переключатель «этот лаунчер ↔ Google TV» прямо в настройках, через ADB самого ТВ на порту 5555.

## Установка

Нужен ТВ на Android 12 (API 31) или новее. Переключение домашнего экрана рассчитано на Google TV.

В каждом [релизе](../../releases) один APK `tv-home-*.apk` со встроенным видео 1080p30 из папки `video/`.

```bash
adb connect TV_IP:PORT
```
```bash
adb install -r tv-home-v1.2.N.apk
```

### Сделать домашним экраном

**Из приложения.** Компьютер нужен только для шага 3. Откройте TV Home → Настройки → Домашний экран:

1. Включите режим разработчика: Настройки → Система → Об устройстве → 7 раз нажмите «Сборка ОС».
2. Включите «Для разработчиков → Отладка по USB».
3. Откройте порт 5555 с компьютера: `adb tcpip 5555`. После перезагрузки ТВ порт закрывается, команду нужно повторить.
4. В TV Home выберите «Сопряжение с этим ТВ». ТВ спросит «Разрешить отладку?». Отметьте «Всегда разрешать».
5. Выберите «Сделать этот лаунчер домашним».

Пока порт 5555 открыт, переключать можно в обе стороны в любой момент.

**С компьютера** (запасной вариант):

```bash
scripts/setup.sh TV_IP:PORT tv-home-v1.2.N.apk
```
```bash
scripts/setup.sh --revert TV_IP:PORT
```

Скрипт и переключатель отключают `com.google.android.apps.tv.launcherx` и `com.google.android.tungsten.setupwraith`. Перед этим они проверяют, не сохранена ли Wi‑Fi сеть одним из этих пакетов: при отключении пакета его сеть удаляется. Если сеть сохранена ими, «забудьте» её в настройках и подключитесь заново.

Если лаунчер упадёт 3 раза за 5 минут, вместо него откроется экран восстановления с кнопками «Попробовать снова», «Открыть Android TV» и «Вернуть Android TV».

### Ключи для ленты

CUB работает без ключа. Ключ TMDB берётся в [настройках аккаунта TMDB](https://www.themoviedb.org/settings/api), ключ Кинопоиска — на [poiskkino.dev](https://poiskkino.dev). Откройте в настройках поле ключа и введите его с компьютера:

```bash
adb shell input text 'ВАШ_КЛЮЧ'
```

### Избранное кино

Влево с первой карточки ленты стоит переключатель «Лента ↔ Избранное». Он появляется, когда в избранном есть хоть одна карточка. Кнопка ленты сверху фильтрует оба списка: все, фильмы, сериалы.

- **Из ленты:** долгое нажатие на карточку → «В избранное».
- **Из Lampa:** нужен плагин из этого репозитория. Lampa → Настройки → Расширения → «Добавить плагин», адрес:

  ```
  https://cdn.jsdelivr.net/gh/ad/tv@main/lampa/favorites.js
  ```

  Перезапустите Lampa. Долгое нажатие на карточку в списке → «Плагины» → «TV Home: в избранное». Карточка добавится, Lampa останется на экране.
- **Из Soap TV** ([ad/soap4ad](https://github.com/ad/soap4ad), клиент soap4 для Android TV): кнопка «В избранное ТВ» на экране сериала или фильма. Такая карточка открывается в Soap TV сразу на нужном сериале или фильме. Карточки ленты Soap TV ищет по названию и году: у soap4 нет TMDB id, поэтому совпадение приближённое. Одинаковые название, год и тип из ленты и из Soap TV склеиваются в одну карточку.

Нажатие на карточку избранного открывает её в том приложении, где её открывали последний раз через «Открыть в …». Только что добавленная из Lampa открывается в Lampa, из Soap TV — в Soap TV, из ленты — в приложении из настройки «Открывать в». Открытая карточка поднимается в начало списка при следующем возврате на главный экран.

## Сборка

Нужны JDK 17+ и Android SDK (platform 36).

```bash
./build.sh
```

Без переменных `KEYSTORE_*` APK подписывается локальным ключом `debug.keystore`, он создаётся при первой сборке.

Проверки логики без устройства, после сборки:

```bash
scripts/check.sh
```

Что где лежит:

- `app/src/main` — код и ресурсы приложения;
- `app/src/test` — проверки для `scripts/check.sh`;
- `lampa/favorites.js` — плагин Lampa «TV Home: в избранное»;
- `scripts/setup.sh` — переключение домашнего экрана с компьютера;
- `video/` — встроенное фоновое видео, попадает в APK как asset.

GitHub Actions (`.github/workflows/build.yml`):

- **pull request** — APK в artifacts;
- **push в `main`** — подписанные release-APK и `setup.sh` публикуются в GitHub Release `v1.2.<номер сборки>`. Если секретов с ключом нет, сборка падает: APK с разными подписями не обновляются поверх друг друга.

### Ключ подписи (один раз)

```bash
keytool -genkeypair -v -keystore release.jks -alias tvhome -keyalg RSA -keysize 2048 -validity 10000
```
```bash
gh secret set KEYSTORE_BASE64 --body "$(base64 -i release.jks)"
```
```bash
gh secret set KEYSTORE_PASSWORD
```
```bash
gh secret set KEY_ALIAS --body tvhome
```
```bash
gh secret set KEY_PASSWORD
```

Сохраните `release.jks` и пароли: без них новые версии не встанут поверх установленной. В форке нужен свой ключ: без секретов push в `main` падает.
