# TV Home

Простой и быстрый лаунчер для Google TV (целевое устройство — Google TV Streamer 4K).

- Большие часы и погода: сейчас, сегодня и три следующих дня (MET Norway). Город выбирается в настройках, поиск через OpenStreetMap.
- Фон: 10 цветовых пресетов или видео без звука по кругу. Видео можно взять файлом с устройства, по ссылке (http/HLS) или встроенное 1080p.
- Справа сверху кнопки: видеовходы (HDMI с CEC-именами), все приложения, настройки лаунчера, настройки ТВ.
- Внизу «стеклянная» панель избранного. При возврате на домашний экран фокус стоит на приложении, из которого вы вернулись. Размер плиток: компактные, средние или крупные.
- Мышь:
  - обычная USB/Bluetooth-мышь работает сразу: наведение, клик, правый клик — меню, колесо прокручивает;
  - курсор с пульта: кнопка курсора (по умолчанию `BOOKMARK`, переназначается в настройках) показывает указатель, стрелки двигают, OK кликает, удержание OK — долгое нажатие;
  - курсор работает либо только в лаунчере, либо во всех приложениях через службу специальных возможностей.
- Лента новинок: CUB (Lampa, без ключа), TMDB через прокси Lampa или Кинопоиск (poiskkino.dev). Карточки открываются в Lampa, Кинопоиске или NUM. Лишнее можно скрыть долгим нажатием.
- Переключатель «этот лаунчер ↔ Google TV» прямо в настройках, через отладку по Wi‑Fi.

Решения и их причины описаны в [docs/SPEC.md](docs/SPEC.md).

## Установка

В каждом [релизе](../../releases) один APK `tv-home-*.apk` со встроенным видео 1080p30 из папки `video/`.

```bash
adb connect TV_IP:PORT
```
```bash
adb install -r tv-home-v1.0.N.apk
```

### Сделать домашним экраном

**Без компьютера.** Откройте TV Home → Настройки → Домашний экран:

1. Включите режим разработчика: Настройки → Система → Об устройстве → 7 раз нажмите «Сборка ОС».
2. Включите «Для разработчиков → Отладка по Wi‑Fi».
3. В TV Home выберите «Сопряжение с этим ТВ».
   - Если на ТВ открыт порт 5555 (после `adb tcpip 5555`), ТВ спросит «Разрешить отладку?». Отметьте «Всегда разрешать».
   - Иначе TV Home попросит включить службу «Курсор TV Home» и откроет настройки. Откройте «Отладка по Wi‑Fi → Подключить устройство с помощью кода». Служба сама прочитает код из окна. Вводить код не нужно: Google TV закрывает сервис сопряжения, как только окно с кодом уходит с экрана.
4. Выберите «Сделать этот лаунчер домашним».

После сопряжения переключать можно в обе стороны в любой момент. TV Home сам включает отладку по Wi‑Fi на время команды и выключает её обратно.

**С компьютера** (запасной вариант):

```bash
scripts/setup.sh TV_IP:PORT tv-home-v1.0.N.apk
```
```bash
scripts/setup.sh --revert TV_IP:PORT
```

Скрипт и переключатель отключают `com.google.android.apps.tv.launcherx` и `com.google.android.tungsten.setupwraith`. Перед этим они проверяют, не сохранена ли Wi‑Fi сеть одним из этих пакетов: при отключении пакета его сеть удаляется. Если сеть сохранена ими, «забудьте» её в настройках и подключитесь заново.

Если лаунчер упадёт 3 раза за 5 минут, вместо него откроется экран восстановления с кнопками «Попробовать снова», «Открыть Google TV» и «Вернуть Google TV».

### Ключи для ленты

CUB работает без ключа. Для TMDB и Кинопоиска откройте в настройках поле ключа и введите его с компьютера:

```bash
adb shell input text 'ВАШ_КЛЮЧ'
```

## Сборка

Нужны JDK 17+ и Android SDK (platform 36).

```bash
./gradlew assembleDebug
```

GitHub Actions (`.github/workflows/build.yml`):

- **pull request** — debug-APK обоих вариантов в artifacts;
- **push в `main`** — подписанные release-APK и `setup.sh` публикуются в GitHub Release `v1.0.<номер сборки>`. Если секретов с ключом нет, сборка падает: APK с разными подписями не обновляются поверх друг друга.

### Ключ подписи (один раз)

```bash
keytool -genkeypair -v -keystore release.jks -alias tvhome -keyalg RSA -keysize 2048 -validity 10000
```
```bash
gh secret set KEYSTORE_BASE64 --body "$(base64 -i release.jks)"
```
```bash
gh secret set KEYSTORE_PASSWORD
```
```bash
gh secret set KEY_ALIAS --body tvhome
```
```bash
gh secret set KEY_PASSWORD
```

Сохраните `release.jks` и пароли: без них новые версии не встанут поверх установленной.
